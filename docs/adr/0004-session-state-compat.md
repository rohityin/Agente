# Session and state-file compatibility strategy

The Rust port reproduces Go's persisted-state layer at schema-exact compatibility with a defined tolerant/brittle boundary: sessions JSONL (meta/message/compaction/usage/rename rows), `auth.json`, `config.json`, `models.json`, `skill-pins.json`, and `models-cache.json` load any file Go wrote, and every Rust-written file is readable by Go's tolerant readers. Row shapes, field order, trailing-newline presence, and file layout follow Go; machine emission is verified by **parse goldens** (Go-authored files replayed with semantic equality) plus **byte-locked micro-goldens** for the small serde-free quirk rows, never full-file byte comparison. Unknown keys survive every whole-file rewrite **deep** — at every typed state struct that round-trips from disk — as raw JSON fragments appended after known fields in sorted key order (D10). Rust→Go readability is assured by the S bar by construction and spot-checked only by dev-time differential probing (never CI). Session-specific determinism seams are `Clock` (`started`, filename timestamp) and `IdGen` (session id, filename uuid8). Go is not installed here; fixture bytes are generated later under ticket 13 against ADR-0001's seam injection.

Status: accepted

## Considered options

- **Byte-locked full-file goldens via a Go-shaped emitter**: rejected; ADR 0003 already amended machine JSON to parse-equivalence (ticket 07), and a custom formatter per state file defeats serde for no consumer benefit — state files are parsed, not diffed, by the tools that read them.
- **Parse goldens only, no byte assertions**: rejected; the small serde-free quirk rows (rename row key order `title,type`, usage double-write, six auth objects + zero `expiry`, skill-pins trailing newline) are cheaply freezable and were judged worth locking.
- **D10 root-only preservation**: rejected; it would destroy unknown keys nested inside the six auth provider `ProviderCreds`/`OAuthToken` objects on every token refresh, contradicting D10's stated intent that user- or future-version-written keys survive.
- **D10 deep preservation via one `#[serde(flatten)] BTreeMap<String, Box<RawValue>>` per round-tripped struct**: accepted; uniform, cheap, and re-emits unknown fragments after known fields in sorted order while known fields keep Go declaration order.
- **Freezing a Rust-emitted corpus verified readable by Go at generation time**: rejected (user decision); the S bar plus Go's tolerant readers makes this redundant, and it only becomes meaningful if Rust emission were byte-locked, which it is not.
- **Installing Go now (winget) and generating state goldens as part of ticket 08**: rejected (user decision); 08 is a decisions ticket and the generation pipeline is ticket 13's job. The corpus manifest is written now so 13 can start without re-deriving scope.

## Consequences

- Session module (in `agente-core`, per ADR 0003) reproduces: `sessionLine` row shapes; `hydrateMessageObject` precedence (reasoning → tool-call `name && id` → tool-result `call_id` → image `mime_type` → text) including silent degradation to empty text and nested text/image-only tool-result content, with `arguments` as raw passthrough; tolerant read (CRLF trimmed, unparseable head skipped, last meta wins, compaction replaces transcript, empty-content messages dropped, unknown row types skipped); orphan tool-pair repair with the stub text `tool call was aborted; no result recorded.`; usage rows written with cumulative into both `usage` and `cumulative` (quirk 4) and delta derivation with `nonNegDelta` plus cache/`cost_usd` clamps; O_APPEND reopen, per-row `writeLine` + flush, fresh-file deletion with zero appended messages; `PruneEmptySessions`/`ListSessions` (mtime desc, path tiebreak)/`RenameSession` (append `{"title","type":"rename"}`, sorted keys); fork/reparent (`Parent`/`ForkPoint`, byte-copy pre-branch pre-compaction, re-marshal post-compaction, title from last user text); portable export/import (meta rewritten, non-meta rows streamed verbatim). Path scheme `sessions/<hex sha256(cwd)[:8]>` (8 bytes → 16 hex chars); filename `<UTCstamp 20060102-150405>-<uuid8>.jsonl` unrelated to `meta.id` (quirk 5).
- `auth.json`: six provider objects always emitted plus `additional_api_key_creds`; zero `oauth.expiry` emitted; mutation rules exactly as Go (SetAPIKey clears command/OAuth except OpenAI; SetOAuth carries refresh token/account id/id_token across refreshes); temp+rename 0600 with Go's fixed `.tmp` race semantics; deep D10.
- `config.json`: 31 top-level keys; tri-state `Option<bool>`/`Option<i32>`/`Option<f32>` mirroring Go's `*bool`/`*int`/`*float32`; always-emitted `provider/model/reasoning/theme`; precedence flag > config > default; `SaveConfig` re-reads only `keymap`, direct non-atomic write, unknown keys deep-preserved; 2-space indent, no trailing newline.
- `models.json` read-only tolerant load (whole-file reject on parse error), precedence user > live > catalog, numeric zero fields do not override; `skill-pins.json` sorted arrays, `CreateTemp` 0600 + rename, trailing newline, corrupt file refused with `invalid skill-pins.json`, deep D10; `models-cache.json` PascalCase keys and a parse golden (Go has none; Rust adds one).
- Verification: parse goldens + micro byte-quirks + behavior tests; full corpus manifest (source Go tests, normalization, artifact list) at `.scratch/rust-port/research/session-state-fixture-corpus.md`; fixture bytes generated at ticket 13 with Clock/IdGen seam injection.
